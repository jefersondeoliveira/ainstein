Aula 3 — Produto Escalar e Ortogonalidade
O produto escalar é uma das operações mais fundamentais em álgebra linear. Dado dois vetores u e v, o produto escalar é definido como a soma dos produtos de suas componentes correspondentes.
# Produto escalar em Python
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

resultado = np.dot(u, v) # = 32
Dois vetores são ortogonais quando seu produto escalar é igual a zero — o que significa que formam um ângulo de 90° entre si.
