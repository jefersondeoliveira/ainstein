Produto Escalar e Ortogonalidade
O produto escalar é uma das operações mais fundamentais em álgebra linear. Dado dois vetores u e v, o resultado é a soma dos produtos de suas componentes.
# Produto escalar em Python
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])
resultado = np.dot(u, v) # → 32
Dois vetores são ortogonais quando o produto escalar é zero — formam 90° entre si.
